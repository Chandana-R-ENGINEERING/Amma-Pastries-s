# 🍰 Amma Pastries – Online Bakery Ordering Platform

A modern and user-friendly online ordering website built for **Amma Pastries**, designed to help customers explore bakery products, place orders, and request customized cakes online.

## ✨ Features

- 🧁 Browse bakery products and pastries
- 🎂 Custom cake ordering
- 🛒 Add products to cart and place orders
- 📅 Select preferred order date and time
- 📝 Add special instructions for orders
- 📱 Responsive design for mobile, tablet, and desktop
- 🔐 Supabase-powered backend
- 📦 Store and manage customer orders
- 📊 Order information stored securely in a database
- ⚡ Fast and modern user interface
- 🎨 Premium bakery-inspired design
